# Synopsis - Battle Tycoon: Flash Hiders SFX (SNES, 1995)

Built from a read of the extracted script (`script/9D-A5.tsv`). A light comedy fighting game.

## Setting
Battle Tycoon is a yearly fighting tournament held in the Central Government City; the winner takes a large prize.
Several fighters are not plain humans: Guston has an old heavy war-era body ("a classic-build Boranzo", he cracks
roads by walking), Calnarsa's chest is ceramic. In Advance mode the player registers a file at the File Management
Center, visits the Item Shop (a Kansai-dialect merchant), the Underground Arena (bet on fights), the Fighters' Lodge
(an inn: rest, status, options, pass time) and the tournament venue, and fights through prelims to the finals.

## Story scenes ("Visuals")

finals, 3 = the ending after winning. One script block per fighter:
