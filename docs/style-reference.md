# Style reference

Voice per speaker and approved example pairs (pilot: Bang's scene 1, 9D-00..13, by the controller). Match this.

## Voices
| Speaker | Voice |
|---|---|
| Bang | Loud, cocky country boy. 俺様 = "the great Bang" / "yours truly" now and then, not every line. Casual slang ("gonna", "ya", "somethin'"), lots of !! |
| Tiria | Quick, snarky, sarcastic; sweet-voiced when teasing (〜 -> "~"). Talks to herself in asides. |
| Ottoh | Never speaks: "..." |
| Harman | Shrill, dramatic, haughty laugh ("Ohohoho!"), うっきー = "Grrrr!"; gushing and girly with Spenoza (keeps the ♥). |
| Spenoza | Mild, very polite, a little flustered ("Ah, Bang-san."). |
| Calnarsa | Tough-talking, man-crazy (あたい: rough grammar, "ya", "gonna"). |
| Rira / Rei | Sugary, giggly, stretched vowels ("Onee-samaaa~"). |
| Seena | Polite, ladylike (ですわ = refined phrasing, no slang), long-suffering; sharp asides in parentheses. |
| Guston | Gruff old soldier, a bit archaic ("Hmph!", "this old warrior", "whippersnapper"); わし = "I". |
| Pachet | Sultry flirt ("Oh my, sweetie", "darling"); turns blunt and rough at the very end of A5. |
| Jail Lance | Dignified dad voice, a bit lecherous. |
| Dairufa | Carefree old gentleman, laughs it off ("Wahaha!"). |
| L.A. | Little kid, blunt. |
| Reporter | TV announcer, chirpy. |
| Menus 47 | Polite receptionist ("Welcome", "Please choose..."). |
| Menus 90 | Friendly innkeeper, casual. |
| Menus 91 | Smooth, polite bookmaker. |
| Menus 92 | Folksy Kansai merchant: warm, a little salesy ("What'll it be?", "Thanks a bunch!"). No phonetic dialect spelling. |

## Corrected example
9D-05 first came out as "Yeah, yeah. Your legend of craziness." The Japanese puns on 最強 (saikyou, strongest)
and 最狂 (saikyou, craziest), which sound the same. Fix: let Bang's line end on "mightiest" and Tiria echo it with
a twist ("The mightiest nutcase alive"), so the joke still lands in English.
